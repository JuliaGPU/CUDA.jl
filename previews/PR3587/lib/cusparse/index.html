cuSPARSE

cuSPARSE.jl offers sparse arrays on the GPU, and NVIDIA's sparse linear algebra routines at three levels:

  • The sparse array types, CuSparseVector, CuSparseMatrixCSR, CuSparseMatrixCSC, CuSparseMatrixCOO and CuSparseMatrixBSR, work with SparseArrays and LinearAlgebra: convert from and to SparseMatrixCSC and CuMatrix, broadcast, multiply with * and mul!, add, and solve triangular systems with ldiv!. This should be the first choice.
  • The functions documented below wrap individual cuSPARSE routines, for when more control is needed. They are named after the operation they compute, as in BLAS, or after the cuSPARSE routine.
  • The generated bindings in libcusparse.jl follow NVIDIA's C API, and change with the CUDA toolkit. Use them together with handle and the descriptors below.

The wrappers follow LinearAlgebra.BLAS's conventions. Character arguments select the variant to compute: transa, transb and transx are 'N', 'T' or 'C', uplo is 'U' or 'L', and diag is 'U' for a unit diagonal or 'N'. Functions whose name ends in ! overwrite one of their arguments, the result, and return it. The index base of the sparse operands is the keyword index: 'O' (the default) for one-based indices as in Julia, or 'Z' for zero-based ones. Routines that offer several algorithms take a cuSPARSE algorithm enum, such as CUSPARSE_SPMV_CSR_ALG2, as an optional last positional argument.

Most wrappers use cuSPARSE's generic API, and check that the installed cuSPARSE supports them. Some only exist in NVIDIA's legacy API: the BSR triangular solves sv2! and sm2!, the incomplete factorizations ic02! and ilu02!, gemvi!, color and prune. NVIDIA has deprecated these, as well as the generic axpby!, rot! and vv!, so they may disappear from a future CUDA toolkit.

Several wrappers share their name with a function in LinearAlgebra, e.g. cuSPARSE.axpby! and LinearAlgebra.axpby!, but are different functions with different arguments. Qualify them with the module name.

cuSPARSE.CuSparseMatrixBSR — Type
CuSparseMatrixBSR{Tv, Ti}

Container to hold sparse matrices in block compressed sparse row (BSR) format on the GPU. BSR format is also used in Intel MKL, and is suited to matrices that are "block" sparse - rare blocks of non-sparse regions.

Construct it from another sparse format or a dense CuMatrix and a block size, as CuSparseMatrixBSR(A, blockDim). The blocks are stored row-major, unless converted from a CSR matrix with CuSparseMatrixBSR{Tv}(A, blockDim; dir='C').

CuSparseMatrixCOO{Tv, Ti}

Container to hold sparse matrices in coordinate (COO) format on the GPU. COO format is mainly useful to initially construct sparse matrices, afterwards switch to CuSparseMatrixCSR for more functionality.

cuSPARSE.bmm! — Method
bmm!(transa, transb, alpha, A::CuSparseArrayCSR, B::DenseCuArray, beta, C::DenseCuArray, [algo]; index='O') -> C

Compute C[:, :, i] = alpha * op(A[:, :, i]) * op(B[:, :, i]) + beta * C[:, :, i] for a batch of CSR matrices A and batches of dense matrices B and C. transa and transb select op ('N', 'T' or 'C').

Dimensions beyond the third are folded into the batch dimension. A batch of size one in A or B is broadcast over the batch of C. C must have more than one column when the batch has more than one matrix. algo is a cusparseSpMMAlg_t, by default CUSPARSE_SPMM_ALG_DEFAULT.

Wraps cusparseSpMM with strided batches. Requires cuSPARSE 11.7.2.

cuSPARSE.color — Function
color(A; index='O', percentage=1.0) -> ncolors, coloring, reordering

Color the adjacency graph of the square sparse CSR or CSC matrix A, which must have a symmetric sparsity pattern: pass A + transpose(A) otherwise. Neighbouring nodes get different colors.

The coloring is approximate, and stops when percentage of the nodes are colored; the other nodes get distinct colors after the last one used. coloring[i] is the color of node i, and reordering is a permutation that groups nodes of the same color together.

Wraps cusparse<t>csrcolor, which NVIDIA has deprecated, for the Float32, Float64, ComplexF32 and ComplexF64 element types.

cuSPARSE.gemm! — Method
gemm!(transa, transb, alpha, A, B, beta, C, [algo]; index='O') -> C

Compute C = alpha * A * B + beta * C for sparse matrices A, B and C, all in CSR or all in CSC format. Only transa = transb = 'N' is supported.

With beta ≠ 0, A * B must have the same sparsity pattern as C; an error is thrown if it has a different number of nonzeros, but a different pattern with the same number of nonzeros is not detected. With beta = 0, the storage of C is replaced when the number of nonzeros differs. algo is a cusparseSpGEMMAlg_t, by default CUSPARSE_SPGEMM_DEFAULT.

Wraps cusparseSpGEMM. Requires cuSPARSE 11.

cuSPARSE.gemm — Method
gemm(transa, transb, alpha, A, B, [algo]; index='O') -> C
gemm(transa, transb, alpha, A, B, beta, C, [algo]; index='O', same_pattern=false) -> D

Compute alpha * A * B, or alpha * A * B + beta * C, into a new sparse matrix, for sparse matrices A, B and C, all in CSR or all in CSC format. Only transa = transb = 'N' is supported.

With same_pattern = true, A * B must have the same sparsity pattern as C, and the result is computed in a copy of C with gemm!. Otherwise alpha * A * B and beta * C are added with geam. algo is a cusparseSpGEMMAlg_t, by default CUSPARSE_SPGEMM_DEFAULT.

Wraps cusparseSpGEMM. Requires cuSPARSE 11.

cuSPARSE.gemv — Function
gemv(transa, alpha, A, x::CuSparseVector, [algo]; index='O') -> CuSparseVector

Compute alpha * A * x for a sparse CSR or CSC matrix A and a sparse vector x, returning a new sparse vector. Only transa = 'N' is supported.

Like gemm, this is a sparse-sparse product, computed by treating x as a sparse matrix with one column. It only pays off when the result is very sparse too: A * x and mul! convert x to a dense vector and use mv! instead. algo is a cusparseSpGEMMAlg_t, by default CUSPARSE_SPGEMM_DEFAULT.

Wraps cusparseSpGEMM. Requires cuSPARSE 11.

cuSPARSE.ic02! — Function
ic02!(A; index='O') -> A

Compute the incomplete Cholesky factorization with zero fill-in, IC(0), of a sparse Hermitian positive definite matrix in place, keeping the sparsity pattern of A. An error is thrown when the factorization hits a zero pivot.

cuSPARSE reads the lower triangle of the matrix as stored row by row. For a CSR matrix, that is the lower triangle of A, which is overwritten with the factor L of A ≈ L * L'. A CSC matrix is processed as the CSR storage of its transpose: its upper triangle is read, and overwritten with the factor R = L' of A ≈ R' * R. BSR matrices follow the conventions of bsric02.

The result is meant as a preconditioner for iterative solvers, applied with ldiv! on triangular views of it.

Wraps cusparse<t>csric02 and cusparse<t>bsric02, which NVIDIA has deprecated, for the Float32, Float64, ComplexF32 and ComplexF64 element types.

source
cuSPARSE.ilu02 — Function
ilu02(A; index='O')

Compute the incomplete LU factorization ILU(0) of the sparse matrix A, like ilu02! but in a copy of A. A can also be a CSR or CSC matrix wrapped in Symmetric or Hermitian, which is first expanded to the full matrix it represents.

cuSPARSE.ilu02! — Function
ilu02!(A; index='O') -> A

Compute the incomplete LU factorization with zero fill-in, ILU(0), of the sparse square matrix A in place, keeping its sparsity pattern. A is overwritten with the factors L, with an implicit unit diagonal, and U of A ≈ L * U. An error is thrown when the factorization hits a zero pivot.

The result is meant as a preconditioner for iterative solvers, applied with ldiv! on triangular views of it.

Wraps cusparse<t>csrilu02 and cusparse<t>bsrilu02, which NVIDIA has deprecated, for the Float32, Float64, ComplexF32 and ComplexF64 element types.

cuSPARSE.mm! — Method
mm!(transa, transb, alpha, A::CuSparseMatrix, B, beta, C, [algo]; index='O') -> C
mm!(transa, transb, alpha, A::DenseCuMatrix, B::CuSparseMatrix, beta, C, [algo]; index='O') -> C

Compute C = alpha * op(A) * op(B) + beta * C for a sparse and a dense matrix, where transa and transb select op ('N', 'T' or 'C') and C is a dense matrix.

In the first form, A can be a CSR, CSC, COO or BSR matrix (BSR from cuSPARSE 12.5.1), and B and C can also be the transpose of a dense matrix, to use row-major storage. In the second form, B can be a CSR, CSC or COO matrix. algo is a cusparseSpMMAlg_t, by default CUSPARSE_SPMM_ALG_DEFAULT. Float16 and ComplexF16 are computed in single precision.

Wraps cusparseSpMM. Before cuSPARSE 11, B and C must be column-major and, unless A is a COO matrix, transb must be 'N'. Before cuSPARSE 12, transa = 'C' is not supported for complex CSC matrices.

cuSPARSE.mv! — Method
mv!(transa, alpha, A::CuSparseMatrix, X::DenseCuVector, beta, Y::DenseCuVector, [algo]; index='O') -> Y

Compute Y = alpha * op(A) * X + beta * Y for a sparse matrix A and dense vectors X and Y, where transa selects op ('N', 'T' or 'C').

A can be a CSR, CSC, COO or BSR matrix. algo is a cusparseSpMVAlg_t, by default CUSPARSE_SPMV_ALG_DEFAULT. Float16 and ComplexF16 are computed in single precision, from cuSPARSE 11.4 and 11.7.2 respectively.

Wraps cusparseSpMV. Before cuSPARSE 12.6.3, BSR matrices use cusparse<t>bsrmv instead, which only supports transa = 'N' and the Float32, Float64, ComplexF32 and ComplexF64 element types. Before cuSPARSE 12, transa = 'C' is not supported for complex CSC matrices.

CuSparseArrayCSR{Tv, Ti, N}

A batch of CSR matrices of the same size and number of nonzeros on the GPU, with the matrices along the third and later dimensions.

CuSparseMatrix{Tv, Ti}

Utility union type of CuSparseMatrixCSC, CuSparseMatrixCSR, CuSparseMatrixBSR, CuSparseMatrixCOO.

CuSparseMatrixBSR{Tv, Ti}

Container to hold sparse matrices in block compressed sparse row (BSR) format on the GPU.

CuSparseMatrixCOO{Tv, Ti}

Container to hold sparse matrices in coordinate (COO) format on the GPU.

CuSparseMatrixCSC{Tv, Ti}

Container to hold sparse matrices in compressed sparse column (CSC) format on the GPU, like SparseMatrixCSC.

CuSparseMatrixCSR{Tv, Ti}

Container to hold sparse matrices in compressed sparse row (CSR) format on the GPU.

CuSparseVector{Tv, Ti}

Sparse vector on the GPU, holding the indices of its nonzeros (Ti, Cint by default) and their values (Tv), like SparseVector.

axpby(alpha, x::CuSparseVector, beta, y::CuSparseVector; index='O') -> CuSparseVector

Compute alpha * x + beta * y into a new sparse vector, for sparse vectors x and y.

geam(alpha, A, beta, B; index='O') -> C

Compute C = alpha * A + beta * B into a new sparse matrix, for sparse matrices A and B that are both in CSR or both in CSC format.
